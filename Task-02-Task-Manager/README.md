
# Task 02: Task Manager

## Overview
The Task Manager is a small Python application designed to help users create, manage, and track their tasks in a simple and organized way.

## What I Built

A CLI-based task manager that allows users to add, view, update, and remove tasks based on a clear workflow and status system.

## Skills Demonstrated
- Python programming
- List and dictionary handling
- Data persistence with JSON
- CRUD-style logic
- CLI application design

## Why It Matters
This project reflects practical utility development and shows how Python can be used to build helpful software for daily use.

## Outcome
The task strengthened my confidence in creating structured applications with real-world functionality.
