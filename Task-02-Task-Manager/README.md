# Task 02: Task Manager

## Overview
The Task Manager is a small Python application designed to help users manage their tasks with tracking and status updates.

## Skills Demonstrated
- Python programming
- data persistence with JSON
- list handling
- task logic and CRUD-style operations
- CLI-based interface design

## Project Goal
Create a system for adding, viewing, updating, and deleting tasks while keeping track of their status.

## Outcome
This project built confidence in practical application design and real-world utility development.
