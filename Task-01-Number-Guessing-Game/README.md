# Task 01: Number Guessing Game

## Overview
The Number Guessing Game is a beginner-friendly Python project that introduces randomness, loops, and interactive logic.

## What I Built
A game in which the player attempts to guess a random number within a limited number of attempts. The program provides feedback after each guess to guide the user toward the correct answer.

## Skills Demonstrated
- Python basics
- Random number generation
- Loops and conditionals
- User interaction
- Game state handling

## Why It Matters

This project demonstrates clarity in logic design and the ability to create an engaging interactive experience using simple Python concepts.

## Outcome
The task improved my understanding of game flow, user input, and decision-making logic.
