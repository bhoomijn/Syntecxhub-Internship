# Task 01: Number Guessing Game

## Overview
The Number Guessing Game is a beginner-friendly Python project that introduces interactive gameplay, loops, and scoring logic.

## Skills Demonstrated
- Python basics
- random number generation
- loops and conditionals
- user interaction
- game state management

## Project Goal
Build a game where the user guesses a random number within a limited number of attempts and receives feedback on their guesses.

## Outcome
This project helped strengthen logic, user experience flow, and gameplay design using Python.
